Télécharger Bialingo

Gratuit, illimité, sans publicité, sans compte et sans collecte de données. Logiciel libre sous licence MIT : le code est public et vérifiable.

Android

Télécharger l'application (APK)

  1. Touchez le bouton ci-dessus depuis votre téléphone.
  2. Ouvrez le fichier téléchargé.
  3. Si Android le demande, autorisez « Installer des applis inconnues » pour Chrome, puis touchez Installer.

L'application n'a pas accès à Internet, ni aux contacts, et fonctionne hors ligne. Le micro n'est demandé que si vous faites un exercice de prononciation (facultatif). Bientôt aussi sur Google Play.

Windows 11

Télécharger et installer (.exe)

  1. Cliquez sur le bouton ci-dessus, puis ouvrez le fichier téléchargé.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : cliquez sur « Informations complémentaires », puis « Exécuter quand même ».
  3. L'installation se fait toute seule, en un clic : l'icône Bialingo (l'abeille) apparaît sur le Bureau et dans le menu Démarrer. Elle fonctionne hors ligne.

Sans installation : Bialingo-Windows-portable.exe. Linux : AppImage ou .deb.

iPhone 13 et iPad

Ouvrir Bialingo dans Safari

  1. Ouvrez ce lien dans Safari (pas dans une autre application).
  2. Touchez Partager (carré avec une flèche vers le haut). Sous iOS 26, il est dans le menu « … » à côté de l'adresse.
  3. Touchez « Sur l'écran d'accueil ».
  4. Sous iOS 26 : laissez activé l'interrupteur qui ouvre le site comme une application web.
  5. Touchez Ajouter. L'icône Bialingo apparaît sur l'écran d'accueil.

L'App Store d'Apple exige un compte développeur payant : l'installation par Safari est gratuite et donne la même application.

Vérifier le fichier Android

Chaque version est fabriquée automatiquement et publiquement par GitHub Actions à partir du code source, puis signée.

  1. Téléchargez SHA256SUMS.txt.
  2. Sous Windows (PowerShell) : Get-FileHash Bialingo.apk
  3. Les deux empreintes doivent être identiques.
